# Customer_Behavior_Analysis
Customer behavior analysis using Python, MySQL, and Power BI to uncover customer spending patterns and insights.

# Customer Behavior Analysis

## Overview

This project analyzes customer behavior and purchasing patterns using **Python, MySQL, and Power BI**.

The project covers the complete data analytics workflow, from loading and cleaning the dataset to performing exploratory data analysis, writing SQL queries, creating an interactive dashboard, preparing a report, and presenting the findings through a PowerPoint presentation.

---

## Dataset

The dataset contains customer-related information such as:

* Customer demographics
* Purchase information
* Product categories
* Review ratings
* Discounts
* Purchase amounts
* Customer behavior attributes

The dataset was loaded and analyzed using Python before being transferred to MySQL for SQL-based analysis.

---

## Tools & Technologies

* **Python** — Data loading, cleaning, and EDA
* **Pandas** — Data manipulation and analysis
* **Matplotlib / Seaborn** — Data visualization
* **Jupyter Notebook** — Analysis environment
* **MySQL Workbench** — SQL analysis
* **Power BI** — Interactive dashboard
* **Gamma** — PowerPoint presentation
* **Microsoft Word / Report** — Project documentation

---

## Project Steps

### 1. Load Dataset

The dataset was loaded into Python using Pandas and inspected to understand its structure, columns, data types, and overall quality.

### 2. Data Cleaning

The dataset was cleaned to improve data quality and consistency.

Key cleaning tasks included:

* Handling missing values
* Replacing missing `review_rating` values using category-level median values
* Checking and handling duplicate records
* Standardizing column names using lowercase and underscores
* Checking data types
* Comparing similar columns to identify duplicate information

### 3. Exploratory Data Analysis (EDA)

EDA was performed to understand customer behavior and identify useful patterns.

The analysis included:

* Customer purchase behavior
* Purchase amount analysis
* Product category analysis
* Review rating analysis
* Discount usage
* Customer spending patterns
* Relationships between different variables
* Data visualizations

### 4. SQL Analysis

The cleaned dataset was uploaded to **MySQL** and analyzed using SQL queries.

SQL analysis included:

* Customer-level analysis
* Average purchase analysis
* Discount usage analysis
* Category-level analysis
* Spending behavior
* Filtering and grouping data
* Aggregate functions
* Subqueries and CTEs

### 5. Power BI Dashboard

An interactive **Power BI dashboard** was created to present the major findings visually.

The dashboard includes:

* KPI cards
* Customer behavior analysis
* Purchase analysis
* Category insights
* Discount analysis
* Interactive filters and slicers
* Data visualizations

### 6. Report

A detailed project report was prepared to document:

* Project objectives
* Dataset information
* Data cleaning process
* EDA findings
* SQL analysis
* Power BI dashboard
* Key insights
* Conclusions

### 7. Presentation

A PowerPoint presentation was created using **Gamma** to summarize the project, methodology, analysis, dashboard, and key findings in a presentation-friendly format.

---

## Dashboard

The Power BI dashboard provides an interactive view of customer purchasing behavior.

Users can interact with the dashboard using filters and slicers to explore different customer segments, categories, and purchasing patterns.

## Results

The analysis helped identify important patterns in customer behavior, including:

* Customer purchasing patterns
* Spending behavior
* Product category performance
* Discount usage
* Review rating patterns
* Relationships between customer attributes and purchase behavior

The combination of **Python, SQL, and Power BI** provided both detailed analysis and an interactive way to communicate the results.


It showcases the practical use of **Python, SQL, and Power BI** to transform raw data into meaningful business insights.
